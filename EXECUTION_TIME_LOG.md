## Optimization Notes

### V6 Optimizations Applied

- GlobalAveragePooling for 2048-dim features

- Cached results (skips if already done)

**Stage 2 (YOLO):**

- GPU acceleration if available
- Optimized inference settings
- Efficient centroid extraction

**Stage 3 (Spatial):**

- NumPy vectorized distance calculations
- Minimal memory footprint

**Stage 4 (Reconstruction):**
- OpenCV VideoWriter with H.264 codec
- Sequential frame reading in optimized order
- Efficient I/O operations

## Timing Variability Factors

Execution times may vary based on:
- **CPU/GPU**: M1 vs Intel vs AMD vs NVIDIA GPU
- **RAM**: Available memory affects caching
- **Storage**: SSD vs HDD speeds
- **Background Processes**: Other apps running
- **Model Cache**: First run downloads models (~250MB)
- **Python Version**: 3.8+ recommended

**First Run:**
- Additional ~2-3 minutes for model downloads
- ResNet50: ~100MB
- YOLOv8x: ~136MB

**Subsequent Runs:**
- Models cached in `~/.cache/`
- Stage 1 may be skipped if CNN output exists
- Consistent timing (~4 minutes total)

### V6 Execution Logger

**Location:** `src/v6_hybrid_yolov8x/logger.py`

The V6 pipeline includes an execution logger that automatically tracks timing and performance metrics for each stage.

**Key Features:**
- Stage-by-stage timing
- Performance metrics (detection rate, step distance, jumps)
- Console output with progress indicators
- Saves log to `execution_log_v6.txt`

**Usage:**
```python
from logger import V6ExecutionLogger

logger = V6ExecutionLogger()
logger.start_pipeline()
logger.start_stage("Stage 1", "Description")
# ... run stage ...
logger.end_stage("Stage 1", "Completed", metrics={'key': 'value'})
logger.end_pipeline(success=True)
logger.save()
```
